
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) — MCP oficial da Microsoft, automacao de browser headless (cliques, screenshots, console/network)

- [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) — MCP oficial do Chrome DevTools, inspeciona DOM, console e rede

- [Claude Code](https://github.com/anthropics/claude-code.git) — CLI oficial da Anthropic para codificacao agentica, fonte de referencia para skills/plugins/MCP do proprio Claude Code
- [Archify](https://github.com/tt-a1i/archify.git) — skill de IA que le o codebase e gera diagramas de arquitetura interativos
- [Context Mode](https://github.com/mksglu/context-mode.git) — MCP que reduz uso de context window: isola execucao em subprocessos, indexa historico em SQLite/FTS5
- [RTK (Rust Token Killer)](https://github.com/rtk-ai/rtk.git) — filtra saida de comandos de shell antes do agente ler, reduz volume lido
- [code-review-graph](https://github.com/tirth8205/code-review-graph.git) — MCP: knowledge graph local (Tree-sitter+SQLite) do codebase p/ review token-eficiente
- [knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins.git) — repo oficial da Anthropic com plugins de papel/equipe p/ Claude Cowork
- [anthropics/skills](https://github.com/anthropics/skills.git) — repo oficial da Anthropic com as skills de referencia do Claude (docx, pptx, xlsx, pdf, mcp-builder etc.)
- [awslabs/mcp](https://github.com/awslabs/mcp.git) — colecao oficial da AWS Labs de servidores MCP por servico AWS
- [github-mcp-server](https://github.com/github/github-mcp-server.git) — MCP oficial do GitHub: repos, issues, PRs, Actions, code search via API
- [agent-browser](https://github.com/vercel-labs/agent-browser.git) — CLI de automacao de browser em Rust (Vercel Labs), sem Playwright/Node
